# SMB Sidekick Skills for Claude

Agent Skills that extend Claude's functionality when used with the 
[SMB Sidekick connector](https://smbsidekick.ai/docs/claude-connector).

## Skills included

### Morning Business Briefing
Generates a structured daily briefing from your call data, sentiment 
trend, and upcoming appointments.

### Weekly Business Review
Synthesizes a week of call data, customer sentiment, and business 
metrics into a saved report on your SMB Sidekick dashboard.

## Requirements
- Active SMB Sidekick account (smbsidekick.ai)
- SMB Sidekick MCP connector added in Claude Settings → Connectors
